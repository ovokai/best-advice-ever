Entry for the make.fun competition **The Best Advice I Ever Got**: a single sentence (up to 200 characters) about the best advice ever received, written by the program to `/output/entry.txt`.

[bounty page](https://make.fun/c/u-pangg7-the-best-advice-i-ever-got-358cefb0)

## Run

```sh
node main.ts
```

Writes the entry line to `/output/entry.txt` (falls back to a local `entry.txt` when `/output` is not writable).
